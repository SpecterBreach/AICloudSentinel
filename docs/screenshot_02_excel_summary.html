Executive Summary (Claude AI)

This OCI environment presents a high-risk posture for its AI workloads. Two critical findings demand immediate action before any additional deployment occurs. The production model weights bucket is publicly readable, exposing fine-tuned model artefacts to unauthenticated access globally — this is both an intellectual property and a supply chain risk.


Simultaneously, an OCI Function handling live inference is storing a provider API key as a plaintext config variable. Any principal with functions:GetFunction permission can extract this credential and make unbilled LLM calls or exfiltrate inference data.


Priority actions: (1) Set Object Storage bucket to NoPublicAccess immediately. (2) Rotate the exposed LLM API key and migrate to OCI Vault. (3) Enforce IMDSv2 on all GPU compute instances.
